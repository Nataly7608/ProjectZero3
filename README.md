# VibeCoding — Лендинг курса по вайб-кодингу

Сайт для продажи курса, который учит создавать сайты и сервисы с помощью ИИ, даже без опыта в программировании.

## Стек

- HTML
- CSS (анимации, градиенты, glassmorphism, адаптив)
- JavaScript (Intersection Observer, аккордеоны, параллакс)

## Особенности

- Тёмная тема с анимированным градиентным фоном
- Плавное появление блоков при скролле
- Парящие сферы с параллакс-эффектом на мышь
- Свечение кнопок и карточек при наведении
- Адаптив под телефон, планшет и десктоп
- Аккордеон для программы курса и FAQ
- Бургер-меню на мобильных

## Целевая аудитория

- Новички без опыта в коде
- Дизайнеры, маркетологи и смежные специалисты
- Те, кто хочет делать свои проекты с помощью ИИ

## Структура

- **Шапка** — навигация с кнопкой записи
- **Хиро** — заголовок, описание, CTA, визуальный блок кода
- **Кому подойдёт** — 3 карточки аудитории
- **Чему научитесь** — 6 навыков
- **Программа курса** — 6 модулей с раскрытием
- **Тарифы** — 3 варианта (Базовый, Стандарт, VIP)
- **FAQ** — частые вопросы
- **Футер** — ссылки и контакты

## Цветовая палитра

Фиолетовый, синий, бирюзовый, розовый, мятный — на тёмном фоне.
